# Screenshots (placeholders)

Dépose ici tes vraies captures avec **exactement** ces noms :

| Fichier | Contenu conseillé |
|---------|-------------------|
| `01-main.png` | Écran principal, timer prêt (ex. 30m · shutdown), fenêtre nette |
| `02-conditions.png` | Panneau conditions ouvert (build Pro si possible) |
| `03-settings.png` | Réglages (thème / MAJ / profils) |

Mêmes fichiers = README GitHub + tu peux les uploader tels quels sur Gumroad.

## Comment faire des captures propres

1. **Résolution** : échelle Windows à 100 % ou 125 % max (évite le flou).
2. **Fenêtre seule** : Win + Shift + S, ou l’outil Capture → “Fenêtre”. Pas tout le bureau avec 40 onglets.
3. **Fond** : un fond uni sombre ou clair derrière la fenêtre, pas ton wallpaper perso / Discord ouvert.
4. **État de l’UI** : vide les messages d’erreur, mets une durée réaliste (`30m`), badge Free ou Pro selon ce que tu vends.
5. **Taille** : ~1200–1600 px de large suffisent. PNG, pas de JPEG compressé à mort.
6. **Gumroad** : 3 images max en hero, dans l’ordre : main → feature Pro → settings. Même crop, même style.

Optionnel : ombre légère + coins arrondis dans un éditeur (Figma / Photopea). Pas obligatoire si la fenêtre est déjà clean.
